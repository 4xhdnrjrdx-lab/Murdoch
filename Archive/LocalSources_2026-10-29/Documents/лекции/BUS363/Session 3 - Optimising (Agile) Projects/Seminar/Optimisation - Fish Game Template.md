## What this is

The blank worksheet for the Session 3 ice-breaker. Students draw a fish twice: first freely, then again by following the lecturer's spoken step-by-step instructions onto this grid, so everyone's output converges toward the same standardised fish. The exercise introduces **Standard Work, Teamwork, Communications, LEAN and Continuous Improvement** (see the Session 3 dump for the full debrief).
