# Проверка восстановления Murdoch

Проверено 7 октября 2026, Asia/Dubai. Репозиторий приватный: [4xhdnrjrdx-lab/Murdoch](https://github.com/4xhdnrjrdx-lab/Murdoch).

## Проверяемая копия

База с текущими LMS-подтверждениями и всеми девятью видео опубликована в коммите `01e54b4759d6d85662e0577f1450481c497a60f6`. Для этого снимка MANIFEST содержит 532 файла, 445 734 492 байта, без собственного рекурсивного хэша manifest. Дополнительный отслеживаемый файл MANIFEST.json защищён Git commit. LFS pointers отсутствуют: документы и видео хранятся как обычные Git blobs.

Первый удалённый clone более раннего снимка `cbf900e90d9d00dc5f00dd101d58b86c16960877` прошёл проверку SHA-256 и Git fsck: 514 файлов, 205 220 654 байта. После восстановления LMS сохранены восемь дополнительных MP4, новые оценки и подтверждения. Полная повторная копия коммита 01e54b4 создана непосредственно из GitHub в отдельной пустой папке `/private/tmp/murdoch-restore-20261007-complete`. PASS: состав, размеры и все 532 SHA-256 совпали, включая WEBM BUS225 и восемь MP4 BUS230. Git fsck --full прошёл без ошибок. Проверка продолжения и семь тестов безопасного клиента прошли в восстановленном клоне, используя только его файлы. После сохранения этого отчёта конечная main дополнительно сверяется в той же восстановленной папке через fetch/pull и verify; текущий SHA сообщается в итоговом ответе и доступен в GitHub.

## Параллельная работа

PASS: два независимых клона и отдельный временный bare remote. Один менял HISTORY BUS219, другой HISTORY BUS230. Проверены отказ при чужих незакоммиченных изменениях, сохранение правок при обновившейся main, коммит своего предмета в отдельной ветке, merge свежей main и последовательное обновление производных файлов. В заключительном клоне обе правки и их история сохранены, verify проходит. Реальные учебные записи этим тестом не изменялись. Подробности: [CONCURRENT_REPORT.json](CONCURRENT_REPORT.json), воспроизводимый код [test_concurrent.py](test_concurrent.py).

## Продолжение без старого Mac

Проверка [test_continuation.py](test_continuation.py) использует только файлы своего клона: восемь предметов, официальные завершённые результаты, исходную сдачу и отдельную просьбу исправить BUS225 A1, оценивание BUS230 A1 без выдуманного числа, BUS334 A2 15/20, группы, полный WEBM, состояние доступа и инструкции нового чата. Никакие прежние разговоры или исходные локальные папки для чтения базы не требуются.

Безопасный клиент Moodle: семь проверок разрешённых операций, отказа в изменениях, защиты параметров/хоста, блокировки outline/редиректа, безопасных ошибок и скрытого декодирования mobile callback прошли. Live API подтвердил userid 257560 и доступ к четырём текущим курсам. Пользователь подтвердил новый ключ в Apple Passwords, запись на iPhone и configure/check access ok. Секреты в Git не помещены; срок ключа неизвестен.

Актуальные сроки и состояния имеют ссылки на источники, поддерживаемая навигация проверяется verify.py. Исторические ссылки сохранённых оригиналов не выдаются за текущую навигацию; соответствие старых путей доступно в инвентаризации.

## Осталось

Исходный постер BUS219, временные изображения некоторых прежних переписок и скриншот итогов TMD сейчас отсутствуют; текстовые свидетельства сохранены. Некоторые учебные сведения неизвестны (например, число баллов BUS230 A1, аудитории, сроки/решения команд). Файлы вне Murdoch не перечислены пользователем. Полный список и способы восстановления: [GAPS.md](../Migration/GAPS.md). Поэтому сохранённая часть базы проверяется как восстанавливаемая, а вся исходная учебная история не объявляется полностью восстановленной.
