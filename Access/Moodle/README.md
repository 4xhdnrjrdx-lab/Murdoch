# Moodle: подключение и восстановление

Код: [moodle.py](moodle.py). Пример конфигурации: [config.example.json](config.example.json). Действующие секреты находятся отдельно от GitHub. При импорте модуль ничего не читает из сети; публичных методов отправки/изменения нет. POST используется только как транспорт для разрешённых операций чтения Moodle API.

## Выпустить или обновить ключ

1. Войти на [Moodle Murdoch](https://moodleprod.murdoch.edu.au/) через университетский SSO. MFA выполняет пользователь.
2. Открыть профиль → Preferences → Security keys. Если пункт отсутствует, обратиться в университетскую поддержку; не угадывать другой service или токен.
3. Получить ключ разрешённого web service. При истечении срока выпустить новый. Не вставлять его в чат, issue, GitHub, URL браузера или пример конфигурации.
4. В приложении «Пароли» создать запись **Murdoch Moodle API**, сайт `moodleprod.murdoch.edu.au`, имя `35553299`, в поле пароля сохранить API-ключ. В заметке указать назначение и срок действия, если он показан. Включить синхронизацию «Пароли и связка ключей» iCloud. Открыть эту запись на iPhone и убедиться, что ключ доступен. Это действие пока ожидает пользователя.
5. На новом компьютере получить ключ из синхронизированной записи или выпустить заново через SSO. В корне клона выполнить:

```sh
python3 Access/Moodle/moodle.py configure
python3 Access/Moodle/moodle.py check
```

Ввод скрыт. `configure` проверяет ключ до замены, сохраняет его в `.secrets/moodle.token` с правами 0600. Папка исключена из Git. При необходимости использовать `--token-file /путь/вне/репозитория/ключ` или `MOODLE_TOKEN_FILE`; секрет не передавать аргументом команды. Текущий пример JSON является описанием параметров, а не файлом, который надо заполнить секретом.

## Читать данные

```python
from Access.Moodle.moodle import Client
client = Client()
info = client.call('core_webservice_get_site_info')
contents = client.call('core_course_get_contents', {'courseid': 31305})
```

Course IDs и периоды берутся из COURSES.yaml. Сроки timestamp переводить в Asia/Dubai. Проверки почты/LMS проводить при начале работы по предмету или запросе статуса, сохранять только нужные сведения, дату и источник. Пустой календарь не отменяет задания из outline. Сырые ответы могут содержать чужие данные; не сохранять всё автоматически.

Сохранённые Unit Outline находятся в Materials/UnitOutline каждого текущего предмета. Повторно скачивать их запрещено; клиент дополнительно блокирует очевидные URL Unit Outline.

Восемь отсутствующих видеолекций BUS230 можно получить после восстановления ключа:

```sh
python3 Access/Moodle/moodle.py download-bus230-videos
```

Команда читает сохранённый список файлов, не Unit Outline. Если ссылки устарели, получить свежий `core_course_get_contents`, выбрать только видеоматериалы и сохранить их через `get_file`. Затем проверить хэши, обновить Migration/GAPS.md, ACCESS_STATUS.json и сохранить изменения по AGENTS.md. Старые snapshot-размеры сами по себе не доказывают совпадение новой редакции лекции.

GitHub login, Apple Account, доступ к iCloud Passwords и университетский MFA восстанавливаются средствами соответствующих аккаунтов. Сохранённый репозиторий не заменяет доступ к этим аккаунтам. Коды восстановления хранить отдельно, доступно с iPhone; в репозиторий их не добавлять.
