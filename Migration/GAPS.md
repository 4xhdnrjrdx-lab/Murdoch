Восемь MP4 BUS230 получены из текущего LMS, все размеры совпали с текущими метаданными; видео теперь входят в MANIFEST.json. Подтверждённый состав и восстановление из GitHub приведены в отчёте проверки. Точный срок действия нового ключа неизвестен; при invalidtoken следовать инструкции обновления.

Для продолжения они не нужны и заново создаются программами. Пустая .tmp_h073 исключена. Локальный Access/Moodle/config.json содержит лишь путь к ключу нынешнего устройства и исключён; на новом устройстве использовать configure по инструкции. Сам старый Moodle-токен, пароли, cookies, GitHub/Apple/MFA-секреты не входили в инвентаризацию и никогда не копируются в Git; доступ восстанавливается через владельца аккаунта и менеджер паролей.
