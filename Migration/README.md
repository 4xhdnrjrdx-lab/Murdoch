# Инвентаризация и перенос 7 октября 2026

[INVENTORY.json](INVENTORY.json) содержит старый путь, новый путь, размер, SHA-256 и решение по каждому исходному файлу. Инвентаризация составлена до копирования. После копирования хэш каждой сохраняемой записи проверен. Точные дубли имеют `action: exact_duplicate` и указывают на единственный сохранённый файл. Разные версии сохраняются отдельно, совпадение имени не считается дублем.

445 исходных файлов в выбранных папках: 392 уникальных сохраняемых файла, 24 дополнительных точных дубля, 29 исключений. Дополнительно получены два оригинальных вложения из Gmail: restaurant blueprint PDF и фактически отправленный DOCX профиля Carrefour. Они также включены в инвентаризацию. Сводки, письма и новый код добавлены после инвентаризации; полный конечный состав находится в MANIFEST.json.

Источник: локальная папка Murdoch. Старые оригиналы оставлены на прежнем месте и исключены из корневого Git; повторно коммитить их не нужно. В локальной папке и BUS225 вложенных Git-репозиториев не было. GitHub 7 октября до создания не подтвердил ни Murdoch, ни bus225-course. Прочтённый чат Bus225 Среда_1 подтвердил остановку предыдущей попытки до создания/push. Существующие посторонние репозитории и их история не менялись.

Имена с двоеточиями и конечными пробелами нормализованы в новых путях для переносимости. Внутренние ссылки и локальные пути в архивных исходниках сохранены как историческое содержание; актуальная навигация работает через новые README и инвентаризацию. Старые генераторы могут содержать прежние пути; для использования на другом устройстве сначала прочитать исходник и выбрать пути нового клона. Это не препятствует восстановлению самих документов.

Нынешний самый большой файл: WEBM BUS225 A1, 73 538 655 байт. Он хранится обычным Git, вместе с реальными байтами, без LFS и дополнительных платных сервисов. GitHub допускает такие файлы, предупреждая от 50 МиБ и блокируя свыше 100 МиБ. [Официальные ограничения GitHub](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github). Проверка базы намеренно останавливает добавление файла от 100 МиБ включительно для отдельного решения.

MANIFEST.json содержит все сохраняемые файлы кроме себя самого и внутренних объектов .git: рекурсивный self-hash невозможен. Сам manifest защищён Git commit. Текстовые преобразования Git отключены через .gitattributes, чтобы исходные SHA-256 совпадали при восстановлении на другом устройстве.

Существенные пробелы и исключения: [GAPS.md](GAPS.md). Результаты удалённого восстановления: [отчёт](../Verification/RESTORE_REPORT.md). Секретов, сырых почтовых заголовков и полного списка получателей группы в новых письмах нет.
