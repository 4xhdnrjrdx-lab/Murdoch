## Ведущему

Открыть `/admin`, нажать Sign in with ChatGPT и войти в аккаунт владельца этого сайта. Если аккаунт создан через Apple, использовать Continue with Apple. Другие аккаунты и анонимные запросы не получают результаты. Allowlist проверяется на сервере через runtime ADMIN_EMAIL. Секретов в исходниках нет.

Панель обновляется каждые четыре секунды: Team 1–3, дополнительные Others, прогресс 0–5, первые ошибки, завершение, детали решений. Start a fresh session начинает чистый сеанс и архивирует прошлые попытки; участники должны войти снова. Allow this team a new attempt освобождает номер при потере телефона, сохраняя предыдущую попытку отдельно. Перед выступлением проверить вход владельца и при необходимости начать чистый сеанс.

## Исходники и восстановление

Source.tar.gz — все 130 отслеживаемых файлов исходного Sites-репозитория в коммите из DEPLOYMENT.json. Не включает node_modules, cookies, runtime-секреты, локальную базу и токены. В отдельной пустой папке распаковать `tar -xzf Source.tar.gz`; проверить все файлы по Source_Manifest.json. Дальше использовать навык Sites: открыть тот же project_id с новой source credential и сохранить аудиторию. Не создавать второй Site. Для сборки использовать штатный install-dependencies.mjs и build-site.mjs установленного Sites plugin. Runtime ADMIN_EMAIL настраивается только через Sites. Hosted D1 не содержится в архиве: это исходники, не экспорт живых ответов.
