## Разбор по вопросам

**1. Почему «Inverted Pyramid» — «frictionless» дизайн письма?**
✅ **d — Grabs attention within milliseconds by placing the most critical information at the top.**
L4, слайд 26: «The email follows the "Inverted Pyramid" model. The most important information is at the top, grabbing attention within milliseconds.» Важное вверху → минимум усилий читателя = низкое трение.

**2. Какой триггер бьёт CRM, отправляя персональную скидку ко дню рождения ради «belonging and safety»?**

**3. Что даёт A/B-тесту «Statistical Significance»?**
✅ **e — Уверенность, что результат не случайность и повторится ~95 из 100 раз.**
L6, слайд 42: «Confidence Level: Most professional tools look for a 95% confidence level. This means if you ran the test 100 times, the same version would win 95 times.»

**4. Главный риск «Mismatched Influencer» в инфлюенс-маркетинге?**

**6. Ядро философии «Fail Forward Fast» (FFF)?**

**7. A/B: Version A 2/10 кликов, Version B 3/10. Почему НЕ менять стратегию?**

## Шпаргалка (на Quiz 3)
- **Нейрохимия:** Dopamine = reward/urgency · Oxytocin = trust/belonging · Cortisol = stress/friction. Hook → Bridge → Scratch.
- **Stat. significance** = 95% confidence; маленькая выборка = «statistical noise».
- **Reiss:** Status = люкс/social standing · Idealism = sustainability/social justice.
- **Lead temp:** интерес без покупки = Warm; открывает, но не берёт = Cold.
- **Unique Identifier** (email/phone) «сшивает» данные через дата-брокеров (Acxiom/Experian/Equifax). **Veblen** = доход/этап жизни по люкс-покупкам.
- **Influencers:** Nano = доверие peer > охват · Mismatched = ценности против бренда · 5 типов: Nano 1K–10K → Micro 10K–100K → Macro 100K–500K → Mega 500K–1M → Celebrity >1M.
- **Friction → cart abandonment.** Inverted Pyramid = важное вверху = frictionless.
- **FFF** = эксперимент + быстрые итерации.
- **PESTLE / drone car:** «first question» = **Legal** («Is this legal?»), НЕ Technological. ← зона ошибки Quiz 2.
- **Porter buyers:** «как легко покупателю уйти».
- **YouTube algo:** Watch Time — главный сигнал вовлечённости.
